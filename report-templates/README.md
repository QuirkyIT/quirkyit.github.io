# QuirkyIT report templates

Editable Markdown templates for the four public worked reports:

- [Public exposure assessment](public-exposure.md)
- [Vulnerability assessment](vulnerability-assessment.md)
- [Logging baseline and handover](logging-baseline.md)
- [Intrusion tripwire deployment](intrusion-tripwires.md)

Use these as the working structure for a client deliverable, together with its controlled evidence pack and action tracker. The public HTML samples demonstrate completed fictional reports. They are not evidence to copy into client work.

Replace every bracketed field. Add one record for every scoped asset, finding, test and exception; tables are starting structures, not row limits. Mark unavailable information as unknown and assign a follow-up owner. Do not imply a test passed if it was not performed. Mark inapplicable sections with a reason rather than silently omitting coverage.

Use the depth needed to support the client's decisions. A concise executive summary sits on top of detailed evidence, analysis and actionable remediation; a page-count target is not a substitute for those details.

Before issue, reconcile inventory totals and findings, verify all evidence references, distinguish observations from inferences, remove secrets and unnecessary personal information, check owners and dates, and record technical review. Match commitments to the signed scope. Send client reports and evidence through the agreed controlled channel; do not commit them to this public website repository.
